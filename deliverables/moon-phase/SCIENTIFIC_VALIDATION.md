# 科學驗證紀錄

## 計算契約（實作前確立）

- 時間輸入皆為 JavaScript `Date` 所代表的 UTC 瞬間；Astronomy Engine 2.1.19 在內部處理 UT/TT 與 ΔT。臺灣顯示及朔起日序使用固定 UTC+8，與主機時區無關。
- 位置核心使用 EQJ：J2000 平赤道直角座標，長度 AU。觀測者用 `ObserverVector(date, observer, false)`，包含地球扁率、自轉、歲差、章動。太空圖用 ECT（當日真黃道），透過庫中旋轉矩陣顯式轉換，不能將 EQJ/ECT/ENU 分量混用。
- 地面使用 ENU：[東、北、天頂]。Astronomy Engine 的 HOR 為 [北、西、天頂]；本程式轉換為 `ENU=[-HOR.y,HOR.x,HOR.z]`。方位角自北向東增加，仰角為幾何仰角，不加大氣折射。
- 相位事件沿用 Astronomy Engine 的 `MoonPhase`/`SearchMoonPhase` 慣例：地心月球黃經減太陽黃經，當日真黃道框架，0/90/180/270 度。其 2.1.19 原始碼內部使用 `GeoVector(...,false)`（不另加年周光行差）；此處不偷偷混入不同定義。三維日月大圓角距獨立計算，不能替代相位黃經差。
- 地表月面視線 `u=normalize(moon-observer)`，光照 `s=normalize(sun-moon)`，來源均為同一日期的 EQJ 向量。受光比例 `k=(1-dot(s,u))/2`；地心版將觀測者設為原點。
- 本地鉛直來自地理緯度定義的地平法線（不是把橢球觀測者位置直接正規化）。畫面右 `r=normalize(u×z)`；畫面上 `v=r×u`；亮側角 `atan2(s·r,s·v)` 自鉛直順時針。分界線角為亮側角加 90 度後折入 [-90,90)；線方向有 180 度等價性。
- 接近天頂或光照天空投影退化時回傳 `angleStable=false`，角度為 `null`，不回傳 NaN。渲染仍用有限的備用基底。
- 沙盒為固定元素兩體模型：解 `M=E-e sinE`，位置 `r=a(1-e cosE)`，真近點角由 E 求得；太陽黃經以 365.256 日週期增加。節點、近地點為沙盒／平均元素概念示意，絕非真實攝動軌道的精確瞬時元素。
- 3D 太空座標映射 `(x,y,z)_ECT → (x,z,-y)_Three`，為保定向旋轉；從黃道北極向下看，月球順行與地球自轉皆逆時針。

## 誤差與適用範圍

- 教學日期範圍為 1900–2100；離線星曆使用 Astronomy Engine，不是 JPL DE 高精度積分。
- 無大氣折射、地形遮蔽、氣象、月面真實地形遮蔽或日月食影錐運算；「地平線以上」只描述幾何條件，不等於肉眼一定可見。
- 月面採球面 Lambert 光照；紋理為程序素材。未實作精確天平動與月球物理自轉。
- 軌道路徑以選定日期固定的 ECT 框架逐時取樣，不視為永久閉合的橢圓。
