# 月相變化 3D 互動實驗室

繁體中文、臺灣高中教學用的互動天文實驗室。真實月球星曆、理想圓軌道及可調參克卜勒模型分開計算；太空、地面天空與月面特寫依同一時刻的日月向量更新。

## Windows 離線使用

1. 將 `moon-phases-3d-offline.html` 保存到自己的電腦；若取得的是原始碼 ZIP，先解壓縮，再找同名 HTML。
2. 用 Chrome 或 Microsoft Edge 開啟 HTML（可直接雙擊，或右鍵「開啟檔案」選擇瀏覽器）。
3. 不需要 Node.js、網路、CDN、安裝套件或本機伺服器。可先中斷網路，再開檔確認。

HTML 已內嵌 JavaScript、CSS、Astronomy Engine、Three.js 與著色器；地球、月球與星空材質在本機程序生成。沒有外部字型或圖片請求。瀏覽器須支援 WebGL；初始化失敗會顯示錯誤訊息。若瀏覽器停用硬體加速，3D 更新可能較慢。

## 四個分頁

| 分頁 | 可操作內容 | 主要問題 |
| --- | --- | --- |
| A 太空 3D | 理想／星曆左右同步、單窗、疊合、俯視、側視、自由旋轉縮放、球體縮尺與傾角視覺倍率 | 模型和真實軌道有何不同？照明從哪裡來？ |
| B 月相與時間 | 五個精確相位跳轉、月齡與臺灣日序、整個朔望月曲線、前後 25 個月間隔圖與表、橢圓／鐘點實驗 | 為何上弦不固定初七／初八？ |
| C 地面觀測 | 地表視差、地平天空、地平鎖定月面、經緯度、參考大圓、四組一鍵比較 | 為何同一上弦的月面相對地平有不同方向？ |
| D 探索與驗證 | e、i、Ω、ω、初始相位、面積定律、i=0 的反例、預測題 | 軌道變速和地平參考系是否是同一原因？ |

預設範例為 2026 年 11 月 17 日的精確上弦（臺中地平線上）；「現在」會讀取使用者電腦時間。

共用時間列可播放、暫停、反向播放，單步 ±1 小時／±1 天，切換每秒 1h／6h／1d／7d，並拖曳本次朔望月的時間軸。五個相位按鈕透過天文搜尋求根，不以固定天數近似。

點「收合控制／投影」可暫時隱藏時間列、參數列與頁首，把畫面留給 16:9 投影；再次點選即可恢復。

拖曳太空畫面可旋轉，滾輪或雙指可縮放；左右視窗共用相機方向。地面天空拖曳可轉頭、仰望；使用「跟隨月球／保持地平水平」做角度比較，避免相機滾轉造成假傾角。

觀測者緯度範圍為 −65°～+65°，經度為 −180°～+180°。經度向東為正；臺中預設約 24.15°N、120.67°E。幾何地平以下的位置會明確標示；「透視地平線下」僅供學習，不代表可實際觀測。薄暮、白天和近朔的顯示同樣不能保證肉眼可見。

「匯出 PNG」保存目前畫面與日期／座標／模式標記；「資料 CSV」匯出可重現的朔與上弦時刻及間隔。實際可用性與測試結果見 [SCIENTIFIC_VALIDATION.md](SCIENTIFIC_VALIDATION.md)。

## 三個推薦課堂實驗

1. **上弦不固定初八**：B →「上弦」→ 看「朔後經過的月齡」與「本次朔起農曆日序」→ 點「前後 25 次朔 → 上弦」不同柱狀 → 操作橢圓離心率／近地點方向，再只改朔發生鐘點。比較得到：軌道角速度改變到達 90° 的實際間隔；民用午夜計日另會改變日序。兩者必須分開。
2. **同一瞬間，不同地平線**：C →「① 鎖定上弦，改變緯度」或「④ 北／南半球切換」→ 保持跟隨月球與地平鎖定 → 比較照明比例、仰角和分界線有號傾角。地心上弦時刻相同，而當地的地平基底不同。
3. **傾斜不是 5.145° 的直接同義詞**：D →「反例：i=0°，月面仍會傾斜」→ 看假設軌道與同一模型的地平月面 → 切換比較緯度／時刻 → 回到平均元素示例。即使月軌道共黃道面，只要觀測者與日月方向適當，分界線仍可相對地平傾斜。改變離心率則主要改變角速度，不能單憑 e 解釋月面的整體旋轉。

## 科學計算與座標約定

- 所有日期都代表同一 UTC 瞬間。Astronomy Engine 2.1.19 在內部處理 UT、TT 與 ΔT。介面可切換固定 UTC 時差；預設臺灣 UTC+8。臺灣朔起日序永遠依 UTC+8 的民用日期計算，不受主機時區影響。固定 UTC−5 並不自動處理夏令時間。
- 真實日月位置以 **EQJ（J2000 平赤道座標）、AU** 計算。觀測者用 `ObserverVector(date, observer, false)`；日月與觀測者先在同一框架相減，再轉換到本地 ENU。當日黃道 ECT 與 EQJ 之間使用 Astronomy Engine 的旋轉矩陣。
- ENU 分量為 **[東、北、天頂]**。引擎的 HOR 為 [北、西、天頂]，因此 `ENU=[-HOR.y,HOR.x,HOR.z]`。方位角自北向東增加；仰角不加折射。
- 月相事件沿用引擎 `MoonPhase`／`SearchMoonPhase` 定義：地心月球黃經減太陽黃經等於 0°／90°／180°／270°。2.1.19 實作採當日真黃道及 `GeoVector(...,false)`，未另加年周光行差。這是本實作相對「完整視位置」規格的明示近似；沒有將不同定義混入同一求根。和 USNO 的獨立分鐘級比較見驗證紀錄。
- 日月大圓角距與黃經差分開顯示。精確黃經差 90° 的上弦，受光比例不必恰為 50.0000%。
- 月面視線 `u=normalize(moon−observer)`；照明方向 `s=normalize(sun−moon)`。球面法向與 s 的點積決定真正 3D 光照。觀測照明比例為 `k=(1−dot(s,u))/2`，沒有用左／右半圓貼圖代替。
- 地平鎖定畫面使用本地天頂 z，右向 `r=normalize(u×z)`，上向 `v=r×u`。亮側指向角為 `atan2(s·r,s·v)`，由鉛直向右順時針；分界線方向與它相差 90°，並依線方向的 180° 等價性折入 [−90°,90°)。接近天頂或照明天空投影退化時，角度標示不穩定／未定義。
- 太空畫面的保定向映射為 `(x,y,z)_ECT → (x,z,−y)_Three`。黃道北極向上；由黃道北極俯視，地球自轉與月球順行公轉均為逆時針。
- 以恆星月 27.3217 天及地球公轉 365.256 天計算，理想朔望月為 `1/(1/27.3217−1/365.256)≈29.530636` 天，理想朔至上弦約 7.382659 天；太陽方向並未固定不動。
- 克卜勒沙盒透過牛頓迭代解 `M=E−e sinE`，再求真近點角及 `r=a(1−e cosE)`。角速度由位置、速度決定，遵循面積定律。比較實驗將初始平近點角數值對準同一朔方向，再搜尋 90°，不預設每條橢圓皆為 7.38 天。
- 真實軌跡是選定日期前後 ±16 天、每小時取樣並轉入同一顯示日期框架的路徑；它不是永久固定的閉合橢圓。平均元素路徑、升／降交點及近／遠地點均標示為幾何示意，不是精確瞬時攝動軌道。

## 原始碼與重建

HTML 本身完全離線；**修改原始碼後的重建**需要 Node.js 及開發套件。第一次 `npm ci` 需能連線 npm 套件來源。執行成品不需要這些開發套件。

```sh
npm ci
npm run build
npm test
npm run test:browser
```

`npm run build` 使用 esbuild 將 `src/app.js` 與其依賴打成 IIFE，再將程式與 CSS 內嵌 `src/template.html`，產生 `moon-phases-3d-offline.html`。預設建置輸出位於專案的 `dist/`；執行 `node build.mjs ./my-output` 可指定其他資料夾。發布時另複製到交付目錄。建置後的 HTML 可直接以 `file://` 開啟，無 ES module CORS 或相對資源依賴。

| 入口 | 用途 |
| --- | --- |
| `src/app.js` | 四分頁、共用狀態、圖表、操作與匯出 |
| `src/science.js` | 星曆事件、向量轉換、地表幾何、克卜勒模型 |
| `src/space.js` | 太空 Three.js 視窗與軌道標示 |
| `src/ground.js` | 地平天空與真正球面受光月面 |
| `src/template.html`、`src/style.css` | 繁體中文介面與響應式樣式 |
| `build.mjs`、`package-lock.json` | 離線成品建置與精確依賴版本 |
| `tests/science.test.mjs` | 科學計算及獨立年鑑資料比對 |
| `tests/browser.mjs` | 嘗試 file://、離線內容、控制項與 WebGL 驗證 |
| `references/` | USNO 原始資料、來源及搜尋所得日序案例 |

瀏覽器自動測試需要可執行的 Chromium／Chrome。若本機未安裝對應瀏覽器，應依 `tests/browser.mjs` 的執行路徑設定調整；不能把未執行的瀏覽器測試當作已通過。測試腳本與產物記錄會列出實際執行條件。

## 已知限制

- 建議使用 1900–2100；本系統使用 Astronomy Engine 的教學級星曆，未直接內嵌 JPL DE 數值積分資料。事件算法與年鑑在取位、光行差與 ΔT 慣例上有細小差別。
- 只計算幾何地平高度與地表視差。未計入大氣折射、消光、雲、地形遮蔽、有限太陽盤或月面地形；「地平線上」不是肉眼可見保證。
- 未建立日月食影錐與月面地球陰影模型。一般月相由觀測方向及太陽照明造成，不能用本模型預測食的接觸時刻。
- 月面材質是原創程序化教學紋理，沒有科學地形精度；未實作精確天平動或月球物理自轉。月面相對地平線的旋轉不以天平動代替解釋。
- 本次朔起日序採「朔所在臺灣民用日為初一」，並未實作正式農曆月名、置閏或干支。日序不能由月齡直接取整冒充。
- 球體與軌道距離分別縮尺，太陽只以方向標記表示；天空月球角直徑也為方便教學而放大。傾角倍率只改視覺，不回寫物理數值。
- 沙盒是固定元素兩體模型，不含太陽引力攝動；不論怎麼調參，均不宣稱是指定日期的真實月球。
- 接近天頂及朔望投影退化時，方向角本來就不穩定。此時顯示不確定狀態，避免輸出 NaN 或假精確角度。
- 已執行及未驗證的項目以 [SCIENTIFIC_VALIDATION.md](SCIENTIFIC_VALIDATION.md) 為準；本次雲端 Chromium 的管理政策封鎖 `file://`，直接開檔回傳 `ERR_BLOCKED_BY_ADMINISTRATOR`；因此改以載入同一 HTML 內容、封鎖網路完成互動驗證，未宣稱直接檔案導航通過。Linux 上的 Chromium 自動測試不等於已在使用者自己的 Windows 顯示卡及瀏覽器上實測。
